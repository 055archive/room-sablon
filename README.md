# ROOM SABLON - Official Website

Website profil dan katalog portofolio usaha sablon baju custom **ROOM SABLON**.

## 🎨 Karakteristik & Desain
- **Tema Visual**: Hitam Pekat (`#07080a`, `#0b0c10`) dipadukan dengan Abu-abu Gelap Bertingkat (`#12141a`, `#171922`, `#242735`) yang kalem, tidak silau/melelahkan mata, maskulin, dan berkarakter streetwear studio.
- **Tipografi**: *Plus Jakarta Sans* modern dan proporsional.
- **Animasi**: Smooth hover micro-interactions, modal dialog dengan backdrop blur, scroll reveal, dan efek floating.
- **Responsif & Mobile Friendly**: Mendukung semua ukuran layar (Smartphone, Tablet, Laptop, Desktop).

## 💻 Cara Menjalankan Website
1. **Buka Langsung**: Cukup klik dua kali (*double click*) file `index.html` untuk langsung membukanya di browser favorit Anda (Google Chrome, Microsoft Edge, Mozilla Firefox, dll).
2. **Buka via Smartphone**: Anda dapat mengunggah folder ini ke hosting gratis seperti **GitHub Pages**, **Vercel**, atau **Netlify** agar om Anda dan para calon pelanggan bisa langsung mengaksesnya lewat tautan di bio Instagram.
